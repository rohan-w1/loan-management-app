# Loan Management App

A full-stack loan management system built with Python, FastAPI, PostgreSQL, and React.

## Tech Stack
- **Backend:** Python 3.14, FastAPI, SQLAlchemy
- **Database:** PostgreSQL
- **Frontend:** React 18
- **Auth:** JWT tokens
- **DevOps:** Docker, GitHub Actions

## Features
- Borrower registration and loan application
- Loan officer approval/rejection workflow
- EMI calculation and repayment schedule
- Role-based access (Admin, Loan Officer, Borrower)
- PDF reports and dashboard
